# Notice

`dsh-mobile-remote-control` is a local fork based on `@linxin666/dsh-remote-web-ui` version 0.2.5, originally published from <https://github.com/zhu1090093659/dsh-web-ui> under the Apache License 2.0.

The fork keeps the original `LICENSE` and changes the local package/plugin identity and default composition for local DSH Desktop use. Automatic public tunneling is disabled by default; QR pairing, revocable device sessions, LAN mobile pages, workspace/session browsing, chat and task operations remain available.
